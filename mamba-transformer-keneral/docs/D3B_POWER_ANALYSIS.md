# D3b Prospective Power Analysis

Observed source actors: **7**; simulation resamples: **5000**; seed: `20260906`.

This is planning only, not confirmatory evidence. Actor effects are resampled with replacement from the locked D3 persistent-read intervention; the estimate is unstable because only seven actors are available.

| Effect scale | Actors for >=80% dual-CI probability |
|---:|---:|
| 1.0x observed | not reached (4-30) |
| 0.75x observed | not reached (4-30) |
| 0.5x observed | not reached (4-30) |

The 50% and 75% scenarios are sensitivity analyses. The simulation does not justify changing the locked panel or selecting donors after observing errors.
